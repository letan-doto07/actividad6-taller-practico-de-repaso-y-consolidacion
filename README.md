# Repaso General

Proyecto: repasogeneral

Integrantes: (añadir nombres)

Descripción: Repositorio con la suite de retos del taller de repaso general. Contiene entregables, manuales y evidencias.

Estructura:

- docs/ : Entregables formales y manuales
- src/ : Código fuente en C++ con main unificado
- capturas/ : Evidencias de ejecución

## Cómo usar
Compilar con g++:

```bash
g++ -std=c++17 -O2 src/main.cpp -o bin/repasogeneral
./bin/repasogeneral
```

(Reemplazar los archivos PDF en docs/ por las versiones finales)
